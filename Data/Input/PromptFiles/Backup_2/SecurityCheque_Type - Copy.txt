- The cheque number is typically the left-most numeric block in the MICR line.

CRITICAL UAE / DUBAI CHEQUE RULE

For UAE/Dubai bank cheques:

1. Locate the MICR line at the bottom of the cheque.
2. Identify the left-most numeric block before the first MICR separator/symbol.
3. Treat this complete left-most block as the Cheque Number.
4. Preserve all leading zeros exactly as printed.
5. Do NOT truncate, derive, calculate, or modify the value.
6. Ignore all subsequent MICR blocks as they usually represent Account Number and other banking identifiers.

Examples:

MICR:
000080:803510106:6784477001
→ ChequeNumber = 000080

MICR:
000020:300320167:1083382064
→ ChequeNumber = 000020

MICR:
100010:0009710001:1000406877
→ ChequeNumber = 100010

MICR:
000080|803510106|6784477001
→ ChequeNumber = 000080

Extraction Rules:

Rule A:
- If a clearly printed Cheque No., CHQ No., Cheque Number, or NO. field exists on the cheque face, extract that value.

Rule B:
- If the printed cheque number is missing, unclear, or not separately visible, extract the left-most MICR block from the bottom MICR line.

Rule C:
- When both sources are available:
  - Prefer the explicitly printed "Cheque No." field.
  - Otherwise use the left-most MICR block.

Strict Exclusions:

Do NOT extract:
- Account Number
- IBAN
- Customer Number
- MICR middle block (Account Number)
- MICR last block (Bank Identifier)
- Reference Number
- Contract Number

- Project Code

Validation Rules:

- Value must be numeric only.
- Preserve leading zeros.
- No spaces.
- No special characters.
- Value must come from:
  - Cheque No. field, OR
  - Left-most MICR block only.
- Never use middle or last MICR blocks.

Confidence Rules (CRITICAL):

HIGH CONFIDENCE:
- Value found under Cheque No. field.

LOW CONFIDENCE:

SECURITY PERCENTAGE

Business Meaning:

The single percentage of contract value covered by this Security Cheque, matching whichever SecurityType was determined for the document.

Where To Search:

Payment Terms
Security Clauses
Retention Clauses

Rule:

First determine SecurityType (Advance / Retention / Performance / SecurityCheque) using the Key Trigger Phrases.
Locate the percentage stated in that same matched clause only — ignore percentages belonging to any other clause in the document.
If the clause breaks the percentage into sub-components (e.g., "50% Advance... 40% on delivery, 10% on installation"), return the headline percentage only, not a sub-component.
If the matched clause states an explicit percentage — including 0 or 0.00% — return that number as-is.
If the matched clause is marked NA or has no percentage stated, return null.
Return one numeric value only — no "%" symbol, no array, no per-type breakdown.

Examples:
